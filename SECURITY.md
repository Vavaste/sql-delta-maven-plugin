# Security

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Report it privately through a
[security advisory](https://github.com/Vavaste/sql-delta-maven-plugin/security/advisories/new), never in a public
issue, pull request or discussion. Say which version is affected and how to reproduce it, without real passwords or
URLs.

The project has one maintainer and the response is best effort: expect an acknowledgement within a week. Once a fix
is released, the advisory is published.
